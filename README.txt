Hana Radwan - portfolio website
===============================
Open index.html in any browser. No build step.

Files
  index.html         the whole site (HTML + CSS + JS)
  assets/hana.jpg    your photo (hero)
  assets/project-*   project screenshots

Edit
  Colours    :root variables at the top of the <style> block (--accent is the one highlight colour)
  Projects   the three project sections (each has its own GitHub button)
  Services   the three package cards in the Services section (no prices shown)
  Certificates  CERT_URLS array near the bottom of index.html: paste each link between the quotes
  Text       plain HTML, section by section

Publish free: upload the folder to GitHub Pages, Netlify or Vercel.
